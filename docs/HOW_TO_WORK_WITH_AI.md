# AI کے ساتھ کام کرنے کا بیسٹ طریقہ (فون پر)

## مسئلہ کیا ہے
پوری ZIP دینے پر AI سو سے زیادہ فائلیں پڑھتا ہے (تقریباً 150 ہزار ٹوکن) اور جواب لکھنے سے پہلے ہی آپ کی لمٹ ختم ہو جاتی ہے۔
حل: AI کو **پورا کوڈ نہیں**، بلکہ **ایک چھوٹا نقشہ + ایک گائیڈ + صرف وہ 3 سے 10 فائلیں** دیں جن میں کام ہونا ہے (تقریباً 20 سے 30 ہزار ٹوکن)۔

## ایک بار کا سیٹ اپ (5 منٹ)
1. اپنے GitHub repo میں یہ تین فولڈر ڈالیں: `docs/`، `tools/`، `.github/workflows/` (ZIP کھول کر "Upload files" سے)۔
2. بس۔ اس کے بعد ہر push پر GitHub خود `docs/PROJECT_MAP.md` (پورے پروجیکٹ کا ایک ایک لائن کا نقشہ) اپڈیٹ کرتا رہتا ہے۔

## ایک بار اور (ضروری)
GitHub ← Settings ← Actions ← General ← Workflow permissions ← **Read and write**۔ ورنہ map اور edits والے workflows پش نہیں کر سکیں گے۔

## چھ ٹریکنگ فائلیں (AI خود اپڈیٹ کرتا ہے)
`Task.md` (موجودہ کام) · `Planning.md` (قدم) · `Roadmap.md` (ترتیب) · `Pending.md` (باقی) · `Complete.md` (مکمل) · `Goal.md` (مقصد)۔ AI کام ختم کرے تو Pending سے ہٹا کر Complete میں لکھتا ہے اور یہ فائلیں بھی اپنی ZIP میں دیتا ہے۔ تیار پرامپٹ `docs/START_PROMPT.md` میں ہیں (نیا کام، لمٹ کے بعد جاری رکھنا، بلڈ ایرر، UI پالش)۔

## ہر نئے فیچر کے لیے
1. GitHub ← **Actions** ← **Pack context for an AI** ← **Run workflow**:
   - goal: ایک دو جملے میں کام (مثلاً "چیٹ میں پن میسج کا آپشن")
   - keywords: متعلقہ الفاظ (مثلاً `chat bubble`) یا files: فائل کے نام (مثلاً `ChatScreen.kt ChatStore.kt`)
   - deps: yes
2. چند سیکنڈ بعد اس رن کے نیچے **Artifacts ← context-pack** ڈاؤن لوڈ کریں (چھوٹی ZIP)۔
3. Claude میں **نیا چیٹ** کھولیں، ZIP اپ لوڈ کریں اور نیچے والا پہلا میسج بھیجیں۔
4. AI صرف نئی/بدلی فائلوں کی ZIP دے گا۔ اسے repo پر اوپر سے Upload کر دیں (وہی راستے)۔ بلڈ چلائیں۔ نقشہ خود اپڈیٹ ہو جائے گا۔

## پہلا میسج (کاپی کریں)
```
docs/AI_GUIDE.md پڑھو اور اس پر پوری طرح عمل کرو، پھر REQUEST.md میں میرا کام ہے۔
پورا پروجیکٹ مت پڑھو؛ صرف pack کی فائلیں کھولو۔ پہلے 6 لائن کا پلان لکھو، پھر صرف نئی/بدلی ہوئی فائلوں کی ZIP دو
(اصل راستوں کے ساتھ) اور docs/CHANGES_<نام>.md۔ چیٹ میں کوڈ مت لکھو۔
جو چیز ٹھیک چل رہی ہے اسے نہ چھیڑو، اور جو اور مسئلہ نظر آئے وہ بس لکھ دو، بدلو مت۔
```

## اگر کام کے دوران لمٹ آ جائے (اکاؤنٹ بدلنا)
- نئے اکاؤنٹ میں نیا چیٹ، وہی pack (یا نیا بنا لیں) اور لکھیں: "`docs/HANDOFF_STATE.md` کے Next step سے جاری رکھو۔"
- ہر AI کام ختم کرتے وقت `HANDOFF_STATE.md` میں لکھتا ہے کہ کیا ہوا اور اگلا قدم کیا ہے، اس لیے اکاؤنٹ بدلنے سے کام نہیں ٹوٹتا۔

## بڑی فائل میں چھوٹی تبدیلی (ٹوکن بچانے کے لیے)
AI سے کہیں: "یہ فائل بڑی ہے، پوری مت لکھو؛ `docs/edits/001.json` دو۔" پھر وہ فائل repo کے `docs/edits/` میں اپ لوڈ کریں ← Actions ← **Apply AI edits** ← path `docs/edits/001.json`۔ (اگر ایک ٹکڑا نہ ملے تو کچھ نہیں بدلتا اور وجہ لکھی آتی ہے۔)

## بلڈ میں ایرر آئے
GitHub Actions لاگ میں سے **صرف ایرر کی لائنیں** (`e: file.kt: (line, col): ...`) اور وہی فائل بھیجیں۔ پورا لاگ یا پوری ZIP نہیں۔

## اگر GitHub استعمال نہیں کرنا
ZIP کھولیں اور صرف یہ اپ لوڈ کریں: `docs/AI_GUIDE.md`، `docs/ARCHITECTURE.md`، `docs/PROJECT_MAP.md`، `docs/HANDOFF_STATE.md` اور وہ 3 سے 8 فائلیں جو `ARCHITECTURE.md` کی جدول "Feature → files" میں آپ کے کام سے ملتی ہیں۔

## قاعدے
- **ایک چیٹ = ایک فیچر۔** لمبے چیٹ میں ہر پیغام پر پرانی ساری بات دوبارہ گنی جاتی ہے۔
- "پورا کوڈ ریویو کرو" یا "سب چیک کرو" مت کہیں۔
- ایک وقت میں 1 سے 3 فیچر چھوٹے قدموں میں؛ ہر قدم اپنی جگہ مکمل ہو۔
- اگر آپ کے پلان میں Claude Projects ہے تو `AI_GUIDE.md` + `ARCHITECTURE.md` + `PROJECT_MAP.md` ایک بار Project میں رکھ دیں، پھر ہر چیٹ میں صرف pack دیں۔
- ایپ کے اپنے **Workspace** میں بھی یہ کام ہو سکتا ہے: ZIP امپورٹ کریں، ایجنٹ ٹولز سے صرف ضرورت کی فائلیں پڑھتا ہے (آپ کے Gemini/پرووائیڈر کی لمٹ پر چلتا ہے، Claude کی نہیں)۔
